# Kallol Dey — Portfolio

A personal portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

- `data/projects.ts` — your project cards (name, description, tech, links)
- `data/skills.ts` — your stack, grouped by category
- `components/Education.tsx` — education timeline
- `components/Hero.tsx` / `components/About.tsx` — bio and headline copy
- `public/images/` — headshot and travel photos
- `public/resume.pdf` — the file the "Download résumé" button links to

## Deploying

This project is ready to deploy on [Vercel](https://vercel.com):

```bash
npm i -g vercel
vercel
```

Or push this folder to a GitHub repo and import it at vercel.com/new.

## Build

```bash
npm run build
npm run start
```
